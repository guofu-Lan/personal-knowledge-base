# Personal Knowledge Base

Personal knowledge base built from curated Markdown notes and linked source materials.

## Original learning sample

`index.html` is a standalone, interactive Grade 5 first-semester Chinese learning sample. Open it in a browser; it has no build step, external fonts, or third-party media. It includes eight original learning themes, short animated lessons, practice questions, daily tasks, and a one-time school research reminder for November 16, 2026.

The learning route is designed for the Hunan school context and follows the unified Chinese textbook (People's Education Press edition). It is not labeled as a Hunan-specific textbook. Explanations, examples, exercises, scripts, and illustrations in the sample are original; it does not reproduce textbook passages, third-party lesson plans, illustrations, or videos.
